# 🧪 [Medium Test] Grader - 코멘트 데미지 및 중복 검증 (상호작용 테스트)

## 1. 테스트 목적
팀원들이 남기는 코멘트 이벤트가 발생했을 때, 중복 여부(방어 로직)를 정확히 판별하고 유효한 타격에만 데미지를 계산하여 동기화하는지 검증합니다.

## 2. 테스트 시나리오 (Given-When-Then)
* **[Given]**
  * 2번의 성장을 거쳐 현재 체력이 **40,000**인 몬스터가 존재합니다.
* **[When]**
  * `isUniqueComment = false` (동일 유저 중복 코멘트) 조건으로 데미지 로직이 호출됩니다.
  * 그 후, `isUniqueComment = true` (새로운 유저 코멘트) 조건으로 데미지 로직이 다시 호출됩니다.
* **[Then]**
  * 중복 코멘트 호출 시에는 데미지가 적용되지 않고 **40,000**이 유지됩니다.
  * 유니크 코멘트 호출 시에는 정상적으로 **5,000** 데미지가 깎여 **35,000**으로 업데이트되며, 변경된 값이 Redis 캐시에 동기화됩니다.
