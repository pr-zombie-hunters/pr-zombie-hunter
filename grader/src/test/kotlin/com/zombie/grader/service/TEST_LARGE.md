# 🧪 [Large Test] Grader - PR 생애주기 백업 및 Revert 복원 (E2E 테스트)

## 1. 테스트 목적
단일 기능이 아닌 PR의 생애주기(Merge -> Revert)라는 거시적인 관점에서, Redis 백업 저장소를 활용한 데이터 복구 기능이 결함 없이 완벽히 동작하는지 검증합니다.

## 2. 테스트 시나리오 (Given-When-Then)
* **[Given]**
  * 방치되어 체력이 **80,000**까지 팽창한 몬스터(PR)가 존재합니다.
* **[When] 1단계: Merge 발생**
  * 코드 리뷰가 승인되어 PR 상태가 `MERGED`로 변경되는 이벤트가 수신됩니다.
* **[Then] 1단계: 처치 및 백업**
  * 남은 체력(**80,000**)은 즉시 0이 되며 몬스터는 처치(`isDefeated = true`)됩니다.
  * 동시에 소멸 직전 체력인 **80,000**이 Redis의 백업 공간(`hp_before_defeat`)에 안전하게 저장됩니다.
* **[When] 2단계: Revert 발생**
  * 병합된 코드에 치명적인 버그가 발견되어 해당 PR이 `REVERTED` 되는 이벤트가 수신됩니다.
* **[Then] 2단계: 자동 복원**
  * 시스템은 Redis 백업 공간에서 **80,000**이라는 값을 찾아옵니다.
  * 몬스터는 부활(`isDefeated = false`)하고, 체력은 정확히 **80,000**으로 복원되어 다시 알림 대상에 포함됩니다.
