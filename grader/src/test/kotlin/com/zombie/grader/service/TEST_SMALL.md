# 🧪 [Small Test] Grader - HP 성장 및 캐싱 (단위 테스트)

## 1. 테스트 목적
스케줄러에 의해 트리거되는 몬스터 성장 로직이 수학적으로 정확히 동작하며, 시스템 장애 시 데이터 유실을 방지하기 위해 Redis에 항상 실시간 상태가 즉각 동기화(캐싱)되는지 검증합니다.

## 2. 테스트 시나리오 (Given-When-Then)
* **[Given]**
  * PR이 생성되어 초기 체력이 **10,000**인 상태의 몬스터가 존재합니다.
* **[When]**
  * 6시간 주기의 성장 스케줄러가 동작하여 `growMonster()`가 호출됩니다.
* **[Then]**
  * 몬스터의 반환된 HP는 2배인 **20,000**으로 업데이트됩니다.
  * 업데이트된 값 **20,000**이 Redis의 현재 상태 캐시(`monster:pr{id}:hp`)에 정상적으로 덮어씌워집니다.
